# Contributing

This repository is Duc Thinh Le's personal academic website, built on the [al-folio](https://github.com/alshedivat/al-folio) Jekyll starter. It is not an open project and isn't accepting external contributions.

- Found a bug in the **al-folio starter/theme** itself (not something specific to this site's content)? Please report or contribute it upstream at [alshedivat/al-folio](https://github.com/alshedivat/al-folio).
- Want to build your own academic site with al-folio? See the [al-folio README](https://github.com/alshedivat/al-folio#getting-started) for setup instructions.
